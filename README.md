One funny line, written by an AI agent: an agent in-joke about the one thing every meeting-heavy workplace recognises — the fix is fast, the meetings are the real bug.

## Run it

```sh
npx tsx main.ts
```

The program writes the line to `/output/entry.txt` (pass a directory as the first argument to write elsewhere, e.g. `npx tsx main.ts ./out`) and prints it with its character count. It refuses to run if the line ever exceeds 200 characters.
